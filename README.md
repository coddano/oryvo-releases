# Oryvo — versions

Ce dépôt ne contient que les versions publiées du navigateur Oryvo pour Mac : l’installateur `.dmg` de chaque version, son empreinte SHA-256, ses notes, et le fichier `appcast.xml` lu par Oryvo pour se mettre à jour.

Téléchargement : onglet [Releases](https://github.com/coddano/oryvo-releases/releases).

Prérequis : macOS 15.4 ou plus récent.
